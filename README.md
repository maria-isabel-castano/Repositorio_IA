# 🧠 AI & Machine Learning Lab

This repository serves as a professional log of my journey through **Artificial Intelligence**, **Data Science**, and **Machine Learning**. Here, I document my experiments, technical scripts, and learning milestones.

### 📁 Project Folders
- **/Automation-Scripts:** Custom Python tools for data processing, file management, and workflow optimization.
- **/NLP-Basics:** Exploratory projects focused on text cleaning, sentiment analysis, and Natural Language Processing.
- **/ML-Models:** Initial implementations of classification, regression, and clustering algorithms using Python and KNIME.

### 🛠️ Setup & Usage
Most of these projects are designed to be executed in **Google Colab** or local **Jupyter Notebooks**.
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt` (where applicable).
3. Open the `.ipynb` files to see the step-by-step analysis.
